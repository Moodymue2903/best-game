SKEWERFEST — grill skewers over live coals and serve the festival crowd before closing time. A complete HTML5 canvas game: read the icon-only ticket, build a skewer from the ingredient bins, grill it to the golden window (perfect 60–80% pays 1.5×), and serve the matching customer. Three nights (targets 8/12/16), wind on Night 2, rain on Night 3, four customer types (Runner, Regular, Family, Critic), an upgrade shop between nights, and a combo multiplier up to ×5. Win by serving the night's orders with fewer than 5 walkaways; lose on 5 walkaways or a missed target at closing.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080.
